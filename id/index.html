    Struktur Folder Storage Game

    Game otomatis menyiapkan struktur folder kerja di memori internal HP:

    /sdcard/STARBLAST/
├── character.conf          # Daftar karakter aktif yang dimuat ke roster
├── characters/             # Folder aset karakter eksternal
│   ├── fighter/            # Folder karakter petarung utama (Playable)
│   ├── assist/             # Folder karakter bantuan (Striker)
│   └── mosou/              # Folder musuh mode Mosou
└── docs/                   # File dokumentasi (bisa dibaca offline)
    ├── site/               # Versi web HTML (tinggal buka index.html di browser)
    ├── id/                 # File markdown Bahasa Indonesia
    └── en/                 # File markdown English
