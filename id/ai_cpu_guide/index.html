    Guide AI CPU (ai.cpu)

    Panduan lengkap bikin dan tuning behavior AI bot untuk fighter di STARBLAST pakai format .cpu deklaratif.

    Jalur Loading File AI (1 Path Folder Fighter)

    STARBLAST menerapkan sistem 1 jalur tunggal untuk loading file AI CPU. Engine langsung membaca file konfigurasi AI di dalam folder fighter masing-masing. Tidak ada lagi scan folder global atau fallback terpisah.

    Prioritas Resolusi:

    1. External Storage (/sdcard/STARBLAST/):
    2. characters/fighter/<char_id>/ai.cpu (Mod / override fighter eksternal)
    3. Parent Folder SWF:
    4. Lokasi file ai.cpu tepat di samping file .swf fighter.
    5. Built-in Assets APK:
    6. assets/characters/fighter/<char_id>/ai.cpu

    Nama File AI

    Nama file standar adalah ai.cpu. Kalau di character.json kalian set nama custom via "ai": "custom.cpu", engine bakal prioritaskan nama file tersebut, tapi wajib tetap berada di dalam folder fighter yang sama. (Assist / striker tidak memerlukan file AI).

    4 Bagian Utama File .cpu

    Format file .cpu dibagi ke dalam 4 section:

    Menentukan playstyle dasar dan behavior bot: 

    [AI]
style = rushdown
preferred_spacing = 48
aggression = 1.45
defensiveness = 1.35

    Menentukan jarak horizontal ($X_{\text{min}}, X_{\text{max}}$ dalam pixel) kapan move/skill boleh dieksekusi: 

    [Ranges]
attack = 0, 145
attackAIR = 0, 155
skill1 = 0, 240
skill2 = 0, 180
zhao1 = 40, 320
bisha = 0, 260
bishaSUPER = 0, 290

    Menentukan normal chain combo dan cancel window ke skill: 

    [Combo]
normal_chain = 砍1, 砍2, 砍3, 砍4, k5
cancel_chain = 砍2, 砍3, 砍4

    Conditional rules untuk eksekusi taktis (hit-confirm, auto-guard, atau punish): 

    [State -1, HitConfirm_Skill1]
name = Kan3_To_RapidSlash
trigger_action = 砍3, k3b
trigger_dist_x = 0, 220
trigger_hit = true
action = skill1
priority = 285
chance = 0.95

    Setting Parameter [AI]

    Parameter Tipe Value Valid Keterangan
    style String rushdown, aggressive, zoner, defensive, balanced Playstyle archetype utama. Tipe rushdown bakal agresif dash ngejar musuh saat jarak jauh ($>170\text{px}$) dan kasih pressure konstan waktu close range.
    preferred_spacing Number 45 - 120 Jarak horizontal ideal (pixel) yang dijaga bot saat neutral game / footsies.
    aggression Number Default 1.0 (misal: 1.45) Multiplier frekuensi serangan dan inisiatif dash forward.
    defensiveness Number Default 1.0 (misal: 1.35) Multiplier reflek tangkisan (guard) saat lawan start animasi attack.

    Move Mapping & Action di [Ranges] & [State -1]

    Action Tombol Default Deskripsi
    attack J Normal ground attack (kanmian).
    attackAIR Air J Normal aerial attack (tkanmian).
    skill1 U Skill 1 / projectile jarak jauh (kj1mian).
    skill2 I Skill 2 forward / thrust cepat (kj2mian).
    zhao1 W + J Special up attack / Anti-Air (zh1mian).
    zhao2 S + J Special down attack (zh2mian).
    zhao3 W + U Special up followup (zh3mian).
    skillAIR Air U Special move di udara (tzmian).
    bisha I / U+I Super Finisher 1 Bar Qi (bsmian).
    bishaUP W + I Up Super Finisher 1 Bar Qi (sbsmian).
    bishaSUPER S + I Ultimate Finisher 3 Bar Qi (cbsmian).
    assist O Memanggil karakter bantuan / striker untuk support attack.
    ghostStep L Flash step / Shunpo dodge berkecepatan tinggi (makan energy).
    downJump S + K Air Recovery / Combo Break saat terlempar atau jatuh.
    waiKai J + K Transformasi / Awakening / Bankai standar.
    waiKaiW W + J+K Transformasi / Awakening varian atas.
    waiKaiS S + J+K Transformasi / Awakening varian bawah.

    Trigger Conditions [State -1]

    Setiap block [State -1, Nama_Rule] mengevaluasi trigger conditions berikut sebelum menembakkan action:

    Parameter MUGEN Alias Tipe Deskripsi
    trigger_action stateno, curaction CSV Nama frame animation aktif (contoh: 砍1, 砍2, 跳砍, 瞬步).
    trigger_dist_x p2dist x Min, Max Jarak horizontal (pixel) ke musuh.
    trigger_dist_y p2dist y Min, Max Jarak vertikal (pixel) ke musuh (nilai minus = musuh di atas).
    trigger_hit movehit Boolean true jika serangan sebelumnya confirmed kena musuh (Hit-Confirm).
    trigger_qi power Integer Syarat minimal Qi meter (100 = 1 Bar, 300 = 3 Bar).
    trigger_energy energy Integer Syarat minimal dash/stamina meter (0 s/d 100).
    trigger_hp life, p1life Expr / Number Sisa HP bot sendiri (misal: < 0.3 atau < 30 untuk Desperation Mode).
    trigger_target_hp p2life Expr / Number Sisa HP musuh (misal: < 0.2 atau < 20 untuk execute finisher).
    trigger_target_air p2air 1 / -1 / Bool 1 jika musuh sedang melayang di udara, -1 jika musuh di darat.
    trigger_target_state p2state String / Int Status musuh: down (jatuh), guard (tangkis), hurt (terpukul), attack (menyerang).
    p2movetype p2movetype String A jika musuh lagi menyerang (dipakai untuk Auto-Guard).
    cooldown cd, delay Integer Durasi jeda frame sebelum rule boleh dieksekusi lagi (anti-spam).
    priority order Integer Prioritas eksekusi (100 - 400). Nilai $\ge 250$ akan override AI bawaan.
    chance rate Float Peluang trigger (0.0 s/d 1.0; 1.0 = 100% pasti tembak).

    Tingkat Kesulitan AI di character.json

    Di character.json, kalian bisa set parameter "ai_level":

    {
  "id": "vergil",
  "name": "Vergil",
  "swf": "vergil.swf",
  "ai": "ai.cpu",
  "ai_level": 4,
  "selectable": true
}
    • 1 : Easy — Delay reaksi bot 3 frame, jarak reflek 60px.
    • 2 : Normal — Delay reaksi bot 2 frame, jarak reflek 85px.
    • 3 : Hard — Delay reaksi 1 frame, predictive attack aktif.
    • 4 : Very Hard / Hell — Respon 0 frame instan tanpa jeda, auto-guard reflek aktif, cadence combo 32% lebih kencang.

    Tips Bikin AI yang Kompetitif

    Wajib Gunakan trigger_hit = true pada Finisher

    Selalu pasang trigger_hit = true di rule move yang mengonsumsi Qi meter (bisha, bishaSUPER). Ini mencegah bot buang-buang bar Qi waktu serangan normalnya luput (whiff).

    Panduan Set Priority

    • Super Finisher / Ultimate: Set priority 350 - 400
    • Combo Cancel / Hit-Confirm: Set priority 260 - 300
    • Neutral Spacing & Harassment: Set priority 200 - 240
