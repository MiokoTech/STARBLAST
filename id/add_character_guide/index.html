    Guide Tambah Karakter Kustom

    Panduan cara pasang fighter baru, assist striker, dan musuh mode petualangan (Mosou) ke game STARBLAST via storage HP (/sdcard/STARBLAST/) tanpa perlu membongkar atau rebuild file APK.

    Quick Setup (3 Langkah Cepat)

    Bikin folder baru untuk fighter di dalam direktori: 

    /sdcard/STARBLAST/characters/fighter/<id_karakter>/
    Gunakan huruf kecil semua tanpa spasi (contoh: vergil, sasuke_uchiha).

    Copy file animasi .swf, config character.json, sprite portrait .png, dan audio .mp3 ke dalam folder tersebut.

    Buka file /sdcard/STARBLAST/character.conf, lalu tambahkan nama folder fighter kalian di bawah section [character].

    Struktur Folder Fighter

    Di dalam folder /sdcard/STARBLAST/characters/fighter/<nama_karakter>/, siapkan file-file berikut:

    /sdcard/STARBLAST/characters/fighter/<nama_karakter>/
├── character.json          # [Wajib] Config data, nama, aset, dan parameter fighter
├── fighter.swf             # [Wajib] Animasi SWF ActionScript 3 (AVM2)
├── face.png                # Icon kecil di grid select screen (48x48 px)
├── face_big.png            # Standing portrait besar saat karakter di-hover/dipilih
├── face_bar.png            # Icon portrait di samping HP lifebar saat match
├── face_win.png            # Artwork kartu victory screen
├── theme.mp3               # BGM battle theme fighter (44.1 kHz stereo)
└── ai.cpu                  # Profil behavior CPU bot (opsional)

    Template character.json Siap Pakai

    Tinggal buat file character.json di dalam folder fighter kalian, lalu paste template berikut:

    {
  "id": "contoh_karakter",
  "name": "Karakter Keren",
  "swf": "contoh_karakter.swf",
  "start_frame": 1,
  "localcoord": "auto",

  "face": "face.png",
  "face_big": "face_big.png",
  "face_bar": "face_bar.png",
  "face_win": "face_win.png",

  "ai": "ai.cpu",
  "ai_level": 3,

  "bgm": "theme.mp3",
  "bgm_rate": 1.0,

  "says": [
    "Bersiaplah menghadapi kekuatanku!",
    "Pertarungan yang sesungguhnya baru saja dimulai."
  ],

  "selectable": true
}

    Parameter Reference

    Parameter Tipe Wajib Default Keterangan & Contoh
    id String Ya Nama folder ID unik fighter (lowercase & underscore, misal: "vergil").
    name String Ya Sama dgn ID Nama display yang muncul di UI / select screen.
    swf String Ya <id>.swf File animasi SWF ActionScript 3.
    start_frame Int Tidak 1 Frame awal MovieClip saat karakter di-spawn.
    localcoord String Tidak "auto" Koordinat canvas (biarkan "auto").
    face String Tidak "face.png" Icon kecil di grid select screen.
    face_big String Tidak Sama dgn face Standing portrait besar waktu fighter di-select.
    face_bar String Tidak "" Icon portrait kecil di samping HP lifebar.
    face_win String Tidak "" Artwork display di victory screen.
    ai String Tidak "" File profil AI CPU (misal: "ai.cpu").
    ai_level Int Tidak 3 Difficulty level CPU (1=Easy, 2=Normal, 3=Hard, 4=Very Hard/Hell).
    bgm String Tidak "" File BGM tema battle fighter (.mp3).
    bgm_rate Number Tidak 1.0 Playback speed BGM (1.0 = normal).
    says Array Tidak [] Voice quote text saat fighter dipilih.
    selectable Bool Tidak true Set false jika ingin menyembunyikan fighter dari roster (contoh: secret boss).

    Standar Format Aset

    Agar performa game tetap smooth dan bebas crash/force close di perangkat Android:

    Animasi SWF (.swf)

    • Engine: ActionScript 3 (AVM2), Flash Player 11+ / AIR runtime.
    • Framerate: Sinkron dengan setting game (30 FPS atau 60 FPS).
    • Standard Frame Labels: zhan (idle/stand), zou (walk), pao (run/dash), tiao (jump), fangyu (guard), kan1-kan4 (normal attack chain), kj1/kj2 (skills), zh1-zh3 (specials), bs/sbs/cbs (super/finisher).

    Sprite & Artwork (.png)

    • Format: True PNG RGBA (dengan alpha channel transparansi).
    • face.png: 48 x 48 px atau 60 x 60 px (rasio 1:1 kotak).
    • face_big.png: 400 x 600 px hingga tinggi maksimal 720 px (canvas 1280x720).
    • face_bar.png: 80 x 80 px (icon status bar).
    • face_win.png: 200 x 300 px (portrait victory).

    Audio BGM (.mp3)

    • Format: MP3 (MPEG-1 Audio Layer III).
    • Sample Rate: 44.100 Hz (44.1 kHz), Stereo 2-Channel.
    • Bitrate: Disarankan 128 kbps (maksimal 192 kbps agar hemat RAM).

    Mendaftarkan Karakter di character.conf

    Buka file /sdcard/STARBLAST/character.conf menggunakan text editor di HP (MT Manager, QuickEdit, ACode, dll.), lalu daftarkan nama folder karakter kalian:

    # STARBLAST character roster

[character]
# Tulis nama folder fighter di sini (satu baris satu nama)
vergil
naruto_sage
sasuke_rinnegan

[mosou_enemy]
# Tulis musuh petualangan Mosou di sini
zetsu_white

[assist]
# Tulis nama folder striker/assist di sini
itachi_assist
pain_assist

    Override Fighter Bawaan APK

    Kalian bisa mengganti animasi, BGM tema, maupun tuning AI dari fighter bawaan APK tanpa perlu membongkar file APK.

    Cukup buat folder di /sdcard/STARBLAST/characters/fighter/ dengan nama ID yang persis sama dengan fighter bawaan APK.

    Contoh: Bikin AI Vergil Jadi Very Hard Tanpa Ubah SWF

    Jika kalian hanya ingin meng-upgrade AI Vergil bawaan APK jadi super jago tanpa mengganti file animasi SWF atau portrait-nya, cukup buat folder: 

    /sdcard/STARBLAST/characters/fighter/vergil/
└── ai.cpu
    Engine game akan otomatis memuat animasi SWF dan portrait Vergil langsung dari dalam APK, sedangkan script AI CPU-nya akan di-override menggunakan file ai.cpu kalian.

    Pasang Karakter Assist (Striker)

    Karakter assist / striker dipanggil sesaat untuk melancarkan serangan bantuan saat Qi meter mencukupi, sehingga tidak memerlukan file AI (ai.cpu).

    1. Buat folder di /sdcard/STARBLAST/characters/assist/<nama_assist>/.
    2. Masukkan file animasi .swf, icon face.png, dan file config assist.json.
    3. Format assist.json: 
      {
  "id": "itachi_assist",
  "name": "Itachi (Assist)",
  "swf": "itachi.swf",
  "face": "face.png"
}
    4. Daftarkan nama foldernya di bawah section [assist] pada file character.conf.

    Troubleshooting & Solusi Error

    Kendala Penyebab Umum & Solusi
    Karakter tidak muncul di select screen 1. Nama folder belum didaftarkan di character.conf di bawah [character].
    2. Di character.json, pastikan "selectable": true.
    3. Cek sintaks JSON, hindari koma berlebih (trailing comma) di baris terakhir.
    Force Close saat memilih karakter 1. File SWF corrupt atau masih ActionScript 2 (engine wajib ActionScript 3 / AVM2).
    2. Missing MovieClip linkage atau symbol Flash di dalam SWF.
    Gambar portrait blank / hitam File bukan PNG transparan asli (contoh: file JPG yang di-rename jadi .png). Wajib re-export sebagai format PNG 32-bit dengan alpha channel.
    BGM battle theme tidak berbunyi Bitrate MP3 terlalu tinggi atau sample rate bukan 44.1 kHz stereo.
    Bot CPU idle / diam saja Nama file di property "ai" tidak matching dengan nama file .cpu di folder fighter.
