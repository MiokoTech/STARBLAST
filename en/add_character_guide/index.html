    Adding Custom Characters

    Official guide for deploying playable fighters, assist strikers, and adventure (Mosou) enemies into STARBLAST via Android storage (/sdcard/STARBLAST/).

    Quick Workflow (3 Steps)

    Create a new character folder under the fighter directory: 

    /sdcard/STARBLAST/characters/fighter/<character_id>/
    Use lowercase characters without spaces (e.g., vergil, sasuke_uchiha).

    Drop the .swf animation file, character.json configuration, .png portraits, and .mp3 battle theme into the folder.

    Open /sdcard/STARBLAST/character.conf and append the folder name under [character].

    Character Folder Structure

    Each character folder in /sdcard/STARBLAST/characters/fighter/<name>/ contains the following files:

    /sdcard/STARBLAST/characters/fighter/<character_name>/
├── character.json          # [Required] Character metadata & parameters
├── fighter.swf             # [Required] ActionScript 3 (AVM2) Flash animation
├── face.png                # Small select grid icon (48x48 px)
├── face_big.png            # Standing portrait on character selection
├── face_bar.png            # Health bar portrait during battle
├── face_win.png            # Victory screen card artwork
├── theme.mp3               # Battle theme music (44.1 kHz stereo)
└── ai.cpu                  # Custom CPU AI behavioral profile

    character.json Configuration

    Save the following JSON template as character.json inside your character folder:

    {
  "id": "example_character",
  "name": "Cool Fighter",
  "swf": "example_character.swf",
  "start_frame": 1,
  "localcoord": "auto",

  "face": "face.png",
  "face_big": "face_big.png",
  "face_bar": "face_bar.png",
  "face_win": "face_win.png",

  "ai": "ai.cpu",
  "ai_level": 3,

  "bgm": "theme.mp3",
  "bgm_rate": 1.0,

  "says": [
    "Prepare to face true power!",
    "The real battle has just begun."
  ],

  "selectable": true
}

    Parameter Reference

    Parameter Type Required Default Description & Example
    id String Yes Folder name Unique identifier (lowercase & underscores, e.g. "vergil").
    name String Yes Same as ID Display name rendered on the game UI.
    swf String Yes <id>.swf Flash SWF binary file containing animations.
    start_frame Int No 1 Starting sprite MovieClip frame.
    localcoord String No "auto" Local canvas coordinate system mode.
    face String No "face.png" Small selection icon.
    face_big String No Same as face Large portrait shown when highlighted.
    face_bar String No "" Small portrait next to the in-game health bar.
    face_win String No "" Round victory screen card artwork.
    ai String No "" CPU AI profile filename (e.g. "ai.cpu").
    ai_level Int No 3 CPU difficulty (1=Easy, 2=Normal, 3=Hard, 4=Very Hard).
    bgm String No "" Character battle theme file (.mp3).
    bgm_rate Number No 1.0 Playback tempo multiplier (1.0 = normal).
    says Array No [] Voice/dialog quotes shown when selected.
    selectable Bool No true Set false to hide character from the select menu.

    Technical Asset Specifications

    Animation Specifications (.swf)

    • Engine: ActionScript 3 (AVM2), Flash Player 11+ / AIR.
    • Frame Rate: Synchronized with engine (30 FPS or 60 FPS).
    • Standard Frame Labels: zhan (idle), zou (walk), pao (dash), tiao (jump), fangyu (guard), kan1-kan4 (normals), kj1/kj2 (skills), zh1-zh3 (specials), bs/sbs/cbs (finishers).

    Graphic Specifications (.png)

    • Format: True RGBA 24-bit or 32-bit with transparency.
    • face.png: 48 x 48 px or 60 x 60 px (1:1 square).
    • face_big.png: 400 x 600 px up to 720 px max height.
    • face_bar.png: 80 x 80 px.
    • face_win.png: 200 x 300 px.

    Audio Specifications (.mp3)

    • Format: MPEG-1 Audio Layer III (MP3).
    • Sample Rate: 44,100 Hz (44.1 kHz), 2-Channel Stereo.
    • Bitrate: Recommended 128 kbps (maximum 192 kbps).

    Registering in character.conf

    Open /sdcard/STARBLAST/character.conf and register folder names under the appropriate section:

    # STARBLAST character list

[character]
# Register playable fighter folder names below (one per line)
vergil
naruto_sage
sasuke_rinnegan

[mosou_enemy]
# Register adventure mode wave enemies below
zetsu_white

[assist]
# Register assist striker folder names below
itachi_assist
pain_assist

    Built-in APK Override Feature

    External characters with the exact same folder name as a built-in character will automatically override that character.

    Example: Overriding Built-in Vergil AI

    To upgrade built-in Vergil's AI to Very Hard without touching his animation SWF or sprites, simply create: 

    /sdcard/STARBLAST/characters/fighter/vergil/
└── ai.cpu
    The game engine automatically loads Vergil's animations and portraits from the APK while overriding his AI behavior with your new ai.cpu profile.

    Assist Strikers

    1. Create a folder at /sdcard/STARBLAST/characters/assist/<assist_name>/.
    2. Drop the .swf animation file, face.png, and assist.json.
    3. Format of assist.json: 
      {
  "id": "itachi_assist",
  "name": "Itachi (Assist)",
  "swf": "itachi.swf",
  "face": "face.png"
}
    4. Register the folder name under [assist] in character.conf.

    Troubleshooting Checklist

    Issue Cause & Solution
    Character not showing up 1. Folder not listed in character.conf.
    2. "selectable" is set to false.
    3. Trailing comma syntax error in character.json.
    Game crashes when selecting 1. SWF file corrupted or compiled in ActionScript 2.
    2. Missing required Flash symbol definitions.
    Face icon is blank or black box Image is a renamed JPG instead of true RGBA PNG with alpha channel.
    Battle theme does not play Bitrate exceeds limits or sample rate is not 44.1 kHz.
    CPU bot remains motionless Filename in "ai" field does not match the actual .cpu filename.
