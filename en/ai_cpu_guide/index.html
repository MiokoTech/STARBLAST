    Creating CPU AI Profiles (ai.cpu)

    Comprehensive specifications, configuration syntax, and behavior scripting rules for designing custom CPU artificial intelligence profiles in STARBLAST.

    AI Profile File Hierarchy (Single-Path Architecture)

    STARBLAST enforces a single-path loading system for CPU AI profiles. The engine strictly searches for the configuration file directly inside the character's own directory. Legacy global AI folders and external fallback scans have been completely deprecated.

    Directory Resolution Order:

    1. External Mobile Storage (/sdcard/STARBLAST/):
    2. characters/fighter/<char_id>/ai.cpu (External / override fighters)
    3. SWF Parent Folder:
    4. Located directly alongside the fighter's .swf binary.
    5. Internal APK Assets (Built-in):
    6. assets/characters/fighter/<char_id>/ai.cpu

    Target Filename

    The standard canonical filename is ai.cpu. If a custom filename is specified in character.json via "ai": "custom.cpu", the engine checks that file first, but it must reside strictly within that character's folder.

    Basic .cpu File Structure

    A .cpu file is divided into 4 core sections:

    Sets baseline psychology and movement parameters: 

    [AI]
style = rushdown
preferred_spacing = 48
aggression = 1.45
defensiveness = 1.35

    Defines horizontal boundaries ($X_{\text{min}}, X_{\text{max}}$ in pixels) for move activation: 

    [Ranges]
attack = 0, 145
attackAIR = 0, 155
skill1 = 0, 240
skill2 = 0, 180
zhao1 = 40, 320
bisha = 0, 260
bishaSUPER = 0, 290

    Defines standard combo sequences and cancellation windows: 

    [Combo]
normal_chain = 砍1, 砍2, 砍3, 砍4, k5
cancel_chain = 砍2, 砍3, 砍4

    Conditional tactical rules and smart move triggers: 

    [State -1, HitConfirm_Skill1]
name = Kan3_To_RapidSlash
trigger_action = 砍3, k3b
trigger_dist_x = 0, 220
trigger_hit = true
action = skill1
priority = 285
chance = 0.95

    [AI] Parameter Reference

    Parameter Type Valid Values Description
    style String rushdown, aggressive, zoner, defensive, balanced Core combat behavior archetype. rushdown fighters aggressively close gaps with dash when $>170\text{px}$ and exert continuous offensive pressure up close.
    preferred_spacing Number 45 - 120 Ideal horizontal pixel distance maintained during neutral footsies.
    aggression Number Default 1.0 (e.g. 1.45) Offensive action frequency and dash initiative multiplier.
    defensiveness Number Default 1.0 (e.g. 1.35) Guard reaction sensitivity multiplier when enemy begins attack.

    Move & Action Mapping in [Ranges] & [State -1]

    Action BVN Button Description
    attack J Standing normal attack (kanmian).
    attackAIR Air J Aerial normal strike (tkanmian).
    skill1 U Projectile / special skill 1 (kj1mian).
    skill2 I Side skill / special skill 2 (kj2mian).
    zhao1 W + J Upward special strike / Anti-Air (zh1mian).
    zhao2 S + J Downward special strike (zh2mian).
    zhao3 W + U Follow-up upward special (zh3mian).
    skillAIR Air U Aerial special skill (tzmian).
    bisha I / U+I 1-Bar Qi Finisher Super (bsmian).
    bishaUP W + I Upward 1-Bar Qi Finisher (sbsmian).
    bishaSUPER S + I Full 3-Bar Qi Ultimate Finisher (cbsmian).
    assist O Summons chosen striker assist for tactical support attack.
    ghostStep L High-speed Flash Step / Shunpo invulnerable dodge.
    downJump S + K Air Recovery / Combo Break when hit or airborne.
    waiKai J + K Standard Transformation / Bankai / Awakening.
    waiKaiW W + J+K Upward variant Transformation / Awakening.
    waiKaiS S + J+K Downward variant Transformation / Awakening.

    Trigger Parameters ([State -1])

    Each [State -1, Rule_Name] evaluates the following triggers before executing an action:

    Parameter MUGEN Alias Type Description
    trigger_action stateno, curaction CSV Current running sprite frame label (e.g.: 砍1, 砍2, 跳砍).
    trigger_dist_x p2dist x Min, Max Target enemy horizontal distance in pixels.
    trigger_dist_y p2dist y Min, Max Target enemy vertical distance in pixels.
    trigger_hit movehit Boolean true only if previous attack connected (hit-confirm).
    trigger_qi power Integer Minimum required Qi meter (100 = 1 Bar, 300 = 3 Bars).
    trigger_energy energy Integer Minimum required stamina/dash energy (0 - 100).
    trigger_hp life, p1life Expr / Number Self remaining HP ratio (e.g.: < 0.3 or < 30 for Desperation).
    trigger_target_hp p2life Expr / Number Target remaining HP ratio (e.g.: < 0.2 or < 20 to execute finisher).
    trigger_target_air p2air 1 / -1 / Bool 1 if target is airborne, -1 if target is on ground.
    trigger_target_state p2state String / Int Target status: down (knockdown), guard (blocking), hurt, attack.
    p2movetype p2movetype String A if target opponent is currently executing an attack.
    cooldown cd, delay Integer Frame cooldown after triggering before rule can fire again (anti-spam).
    priority order Integer Execution priority (100 - 400). Values $\ge 250$ override generic AI decisions.
    chance rate Float Evaluation probability (0.0 to 1.0; 1.0 = guaranteed execution).

    Difficulty Scale ai_level in character.json

    {
  "id": "vergil",
  "name": "Vergil",
  "swf": "vergil.swf",
  "ai": "ai.cpu",
  "ai_level": 4,
  "selectable": true
}
    • 1 : Easy — 3-frame reaction lag, danger radius 60px.
    • 2 : Normal — 2-frame reaction lag, danger radius 85px.
    • 3 : Hard — 1-frame reaction lag, predictive attack enabled.
    • 4 : Very Hard / Hell — 0-frame instant reaction, reactive auto-guard, maximum combo priority.

    Case Study: Vergil AI Profile (Very Hard)

    Rules implemented in assets/characters/fighter/vergil/ai.cpu:

    ; 1. Cancel Normal Kan3 into Rapid Slash on Hit
[State -1, Cancel_Kan3_RapidSlash]
name = Yamato_Kan3_To_RapidSlash
trigger_action = 砍3, k3b
trigger_dist_x = 0, 220
trigger_hit = true
action = skill1
priority = 285
chance = 0.95

; 2. Air Rave Combo: Aerial Slash into Helm Breaker
[State -1, Air_Rave_HelmBreaker]
name = Air_Rave_Helm_Breaker
trigger_action = 跳砍, KJ1.5, KJ2, KJ3
trigger_dist_x = 0, 180
trigger_hit = true
action = skillAIR
priority = 310
chance = 0.98

; 3. Execute Judgement Cut End (1 Bar Qi)
[State -1, Super_JudgementCutEnd_HitConfirm]
name = Super_Judgement_Cut_End_Confirm
trigger_action = 砍3, k3b, 砍4, 砍技1, 招2
trigger_dist_x = 0, 250
trigger_qi = 100
trigger_hit = true
action = bisha
priority = 380
chance = 0.98

; 4. Reactive Guard when Opponent Attacks
[State -1, Reactive_Guard_VeryHard]
name = Yamato_Reactive_Guard
triggerall = p2movetype = A
trigger_dist_x = 0, 130
trigger_dist_y = -60, 60
action = defense
priority = 330
chance = 0.92

; 5. Desperation Ultimate: Sin Devil Trigger (BishaSUPER) when HP < 30% and Qi is Full (3 Bars)
[State -1, Desperation_SinDevilTrigger]
name = Desperation_SDT_Burst
trigger_hp = < 0.3
trigger_qi = 300
action = bishaSUPER
priority = 400
cooldown = 300
chance = 1.0

; 6. Okizeme Assist: Summon Striker when Opponent is Knocked Down
[State -1, Okizeme_Assist_Trap]
name = Striker_Okizeme_Trap
trigger_target_state = down
trigger_dist_x = 0, 160
action = assist
priority = 270
cooldown = 180
chance = 0.85

    Fighters with Transformation / Bankai (waiKai)

    Fighters such as Naruto (Nine-Tails / Sage Mode) or Ichigo (Bankai / Hollow) that feature form transformations (J+K) can use action = waiKai. For Vergil, Sin Devil Trigger is his 3-Bar Ultimate attack, which uses action = bishaSUPER.

    AI Tuning Tips

    Always Use trigger_hit = true on Finisher Supers

    Always apply trigger_hit = true to high-cost super moves (bisha, bishaSUPER). This prevents the CPU from wasting meter when earlier hits whiff.

    Balance Rule Priorities

    • Super Finishers / Bisha: Priority 350 - 400
    • Hit-Confirm Cancels: Priority 260 - 300
    • Spacing / Neutral Harassment: Priority 200 - 240
