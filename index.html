    Fitur Utama Engine

    • Penyimpanan Eksternal (No-Root)

      Bebas tambah, edit, atau hapus karakter kapan saja langsung di /sdcard/STARBLAST/characters/ tanpa perlu bongkar atau rebuild file APK.

    • Declarative CPU AI Engine

      Pakai file .cpu buat atur inisiatif serangan, spacing neutral game, auto-guard reflek, dan hit-confirm combo lanjutan.

    • Support Assist / Striker

      Bisa tambah striker kustom yang bisa dipanggil saat match pertarungan menggunakan Qi meter.

    • Sistem Override Aman

      Bisa replace aset visual, BGM, atau AI petarung bawaan tanpa merusak file core game bawaan APK.
